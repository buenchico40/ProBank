# Seguridad

- No subas secretos, cadenas de conexión, certificados ni `terraform.tfvars` con valores reales.
- Las cadenas de conexión de Consultas dinámicas viven solo en Azure Key Vault.
- Reporta vulnerabilidades a la Gerencia de TI por el canal interno; no abras un issue público.
- Toda dependencia nueva pasa por revisión en el PR (CODEOWNERS).
