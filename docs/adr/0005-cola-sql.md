# Cola y programador sobre SQL Server

- **Estado:** Aceptada
- **Fecha:** 2026-10

## Decisión

Las tareas largas y las consultas programadas usan tablas de cola y un BackgroundService.

## Motivo

Sin infraestructura adicional (Service Bus) en esta versión.

## Consecuencias

Cualquier excepción se registra como un ADR nuevo que reemplaza a este.
