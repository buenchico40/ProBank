# Aprobadores por tarea, no grupo único

- **Estado:** Aceptada
- **Fecha:** 2026-10

## Decisión

Cada tarea tiene ninguno, uno o varios aprobadores; si son varios, aprueban todos.

## Motivo

Decisión del usuario: las reglas de aprobación varían por tarea.

## Consecuencias

Cualquier excepción se registra como un ADR nuevo que reemplaza a este.
