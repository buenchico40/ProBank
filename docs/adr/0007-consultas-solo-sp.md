# Consultas dinámicas solo con procedimientos

- **Estado:** Aceptada
- **Fecha:** 2026-10

## Decisión

No se aceptan queries libres; las bases son configurables y cifradas.

## Motivo

Reduce el riesgo de acceso indebido e inyección.

## Consecuencias

Cualquier excepción se registra como un ADR nuevo que reemplaza a este.
