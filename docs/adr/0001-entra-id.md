# Identidad con Microsoft Entra ID

- **Estado:** Reemplazada por [0010](0010-usuario-y-clave.md) para el inicio de sesión de usuarios
- **Fecha:** 2026-10

## Decisión

Se reemplaza Active Directory on-premise por Entra ID (OIDC, Microsoft.Identity.Web, Graph).

## Motivo

Identidad central en la nube, MFA y acceso condicional; ProBank nunca recibe contraseñas.

## Consecuencias

Cualquier excepción se registra como un ADR nuevo que reemplaza a este.
