# CQRS con despachador propio

- **Estado:** Aceptada
- **Fecha:** 2026-10

## Decisión

Comandos y consultas con interfaces propias y un despachador mínimo, sin MediatR.

## Motivo

Evita dependencias con licencia comercial y mantiene el código explícito.

## Consecuencias

Cualquier excepción se registra como un ADR nuevo que reemplaza a este.
