# Roles y permisos

- Cada usuario entra con su cuenta de Entra ID, puede tener varios roles y trabaja con uno activo.
- Permisos por opción del menú × acción: ver, crear, editar, eliminar/anular, exportar, aprobar, más funciones propias.
- El rol activo se valida en la API y en los procedimientos almacenados; ocultar un botón no es el control.
- Técnicos y aprobadores no son roles: son usuarios asignados en cada tarea, consulta o versión.

| Rol | Responsabilidad |
|---|---|
| Administrador | Todas las opciones; asigna roles y permisos |
| Gerencia de TI | Líder de proyecto: Portafolio, Presupuesto, Versiones |
| Analista de coactivas | Oficios, coactivas y órdenes judiciales |
| Compras TI | Solicitudes, renovaciones y pagos |
| Cumplimiento | Controles, auditorías y hallazgos |
| Seguridad de la información | Certificados, cuentas técnicas y secretos |
| Marketing | Imágenes promocionales y comunicados |
| Consulta | Solo lectura y reportes |
